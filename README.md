# UrbanKart Retail Analytics Dashboard | Power BI

## Project Overview
The **UrbanKart Retail Analytics Dashboard** is an interactive business intelligence project developed using Microsoft Power BI to analyze retail sales, profitability, customer complaints, employee performance, and inventory management. It helps management monitor key performance indicators (KPIs), identify operational challenges, and make data-driven business decisions.

## Dataset Description
The project uses a retail business dataset containing four major data tables:

- **Sales Orders:** Order details, gross sales, discounts, net sales, costs, net profit, delivery days, and product returns.
- **Customer Complaints:** Complaint types, severity, resolution status, resolution time, and customer ratings.
- **Employee Data:** Employee departments, roles, salaries, satisfaction scores, overtime hours, tenure, and exit information.
- **Inventory Data:** Stock levels, inventory value, days on hand, forecast demand, reorder levels, and inventory status.

## Dashboard Features
- Executive overview with Q1 and Q2 performance comparison.
- Sales and profitability analysis by department, city, product category, and sales channel.
- Customer complaint analysis and resolution tracking.
- Employee turnover, satisfaction, and overtime analysis.
- Inventory monitoring to identify low-stock and excess-stock products.
- Interactive filters, KPI cards, charts, and page navigation.

## Tools & Technologies
- Microsoft Power BI
- DAX (Data Analysis Expressions)
- Power Query
- Data Modeling and Relationships
- Interactive Visualizations and Bookmarks

## Project Objective
The primary objective is to transform raw retail data into actionable insights, helping management improve profitability, customer satisfaction, employee retention, and inventory efficiency.

## Key Learning Outcomes
- Building interactive multi-page Power BI dashboards.
- Creating DAX measures for business KPIs.
- Designing relationships between data tables using a date dimension.
- Implementing interactive filters, bookmarks, and quarter-based analysis.
- Presenting business insights through data visualization.

**Note:** This project uses a retail experiential dataset for analytical and educational purposes. Findings depend on the data provided and should not be interpreted as verified real-world company results.
